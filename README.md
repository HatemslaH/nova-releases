# NovaSim

Официальные сборки NovaSim для Windows и Linux x86_64.

NovaSim предназначен для разработки и проверки, не для эксплуатации.

Скачайте установщик Windows либо архив Linux в разделе
[Releases](https://github.com/HatemslaH/nova-releases/releases).
Linux: распакуйте архив и выполните `./NovaSim/install.sh` без sudo.

Установленная NovaSim проверяет и скачивает обновления в фоне.
Установка выполняется по кнопке «Обновить и перезапустить».
Для обновления без сети используйте «Установить из файла» и подписанный
пакет `.nova-update` для своей ОС.

Профиль и пользовательские результаты сохраняются отдельно от установки.
В поставку входит ArduPilot SITL; лицензии и сведения об исходниках находятся
в каталоге `licenses` установленной версии.

Подпись пакетов проверяется встроенным открытым ключом издателя.
